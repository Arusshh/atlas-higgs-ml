# atlas-higgs-ml

Classifying Higgs boson signal (H→ττ) vs. background events from the ATLAS Higgs Machine Learning Challenge 2014 with classical machine learning: a logistic regression and XGBoost baseline, then newer tabular-ML and physics-feature methods, scored with ROC AUC and the challenge's AMS on the original private leaderboard set. A quantum version lives in a separate repo.

## Data

ATLAS collaboration (2014), *Dataset from the ATLAS Higgs Boson Machine Learning Challenge 2014*, CERN Open Data Portal, DOI [10.7483/OPENDATA.ATLAS.ZBP2.M5T8](https://doi.org/10.7483/OPENDATA.ATLAS.ZBP2.M5T8). 818,238 simulated events, 30 features. Not committed; download `atlas-higgs-challenge-2014-v2.csv.gz` into `data/`.
